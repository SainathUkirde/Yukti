# Data Strategy & Provenance Model
## Well-to-Surface Digital Twin — Baghewala Heavy Oil Field

---

## 1. Honesty Statement

> **This prototype uses physics-based synthetic data, calibrated to published petroleum engineering
> literature and the ranges stated in the PS. It has NOT been validated on real Baghewala field
> operations. No claim is made that any dataset contains actual Baghewala, CSS, or SRP operational
> records unless real data is explicitly uploaded via the CSV/API import endpoint.**

---

## 2. Four Data Categories

### Category 1: Physics/Literature Equations (NOT datasets)
Implemented as code inside `/simulator/`. Each equation cites its source.
- Walther/ASTM D341 viscosity–temperature
- Vogel IPR + viscosity-coupled PI
- Marx-Langenheim heated-zone model
- Reservoir cooling decay (exponential)
- Damped 1D wave equation (Gibbs)
- Goodman rod stress criterion
- Pump efficiency (API RP 11L)

### Category 2: Synthetic Data (generated by our simulator)
All Baghewala-specific operational data. Generated by `/data/generate.py` using the
physics simulator with parameters from published heavy-oil/Indian-field literature ranges.

| Dataset | Source | Rows | Key Fields |
|---|---|---|---|
| `production_history.parquet` | Simulator (Phase 2) | 10 wells × 3650 days | date, well_id, oil_rate, water_cut, gas_rate, cum_oil |
| `css_cycle_records.parquet` | Simulator (Phase 2) | ~80 cycles | cycle_n, steam_vol, inj_pressure, soak_days, T_peak, SOR |
| `srp_operating_data.parquet` | Simulator (Phase 2) | 10 wells × 8760 h | SPM, stroke_len, VFD_freq, motor_current, kWh_bbl |
| `dyno_cards_labeled.parquet` | Simulator (Phase 2) | ~50k cards | card_points[200], fault_label, confidence |
| `rod_failure_history.parquet` | Simulator + noise | ~120 events | date, well_id, failure_type, risk_score_at_failure |

### Category 3: Real Public Data (optional, not required)
**Equinor Volve dataset**: Used ONLY to calibrate realistic sensor noise parameters
(standard deviation, drift rate, spike frequency, dropout probability).
- License: Creative Commons Attribution 4.0 (CC BY 4.0)
- URL: https://www.equinor.com/energy/volve-data-sharing
- If NOT downloaded: Gaussian noise with parameters from published literature is used instead.
- The app functions identically whether or not Volve data is present.
- Volve data does NOT contain CSS, steam injection, SRP, or Baghewala data.

### Category 4: NEVER claimed
- We never claim a public dataset contains Baghewala operational data.
- We never claim KPI improvements are field-validated results.

## 3. Provenance Tag System

Every value in the API response and UI carries a `provenance` field.

### Tags

| Tag | Hex Color | Meaning |
|---|---|---|
| `FIELD_FACT` | `#22C55E` (green) | Real, verifiable field/literature fact from the PS |
| `LITERATURE_ASSUMPTION` | `#3B82F6` (blue) | Parameter from published petroleum engineering literature |
| `SYNTHETIC_HISTORICAL` | `#A855F7` (purple) | Pre-generated synthetic history from simulator |
| `SIMULATED_LIVE` | `#F59E0B` (amber) | Live stream tick from the running simulator |
| `ML_PREDICTION` | `#06B6D4` (cyan) | ML model output, includes uncertainty interval |
| `OPTIMIZER_RECOMMENDATION` | `#F97316` (orange) | Joint CSS+SRP optimizer output |
| `DEMO_RESULT` | `#EF4444` (red) | Baseline vs optimized comparison from simulator runs |

### Legend Display
A persistent legend bar is shown in the UI footer and on every chart panel.
Every chart title, KPI card, and recommendation card shows the relevant badge.

### ProvenancedValue Schema (TypeScript)
```typescript
interface ProvenancedValue<T> {
  value: T;
  provenance: ProvenanceTag;
  uncertainty?: { low: T; high: T };  // for ML_PREDICTION
  method?: string;                     // for DEMO_RESULT: method description
  source?: string;                     // for FIELD_FACT / LITERATURE_ASSUMPTION
}
```

### ProvenancedValue Schema (Python/Pydantic)
```python
class ProvenanceTag(str, Enum):
    FIELD_FACT = "FIELD_FACT"
    LITERATURE_ASSUMPTION = "LITERATURE_ASSUMPTION"
    SYNTHETIC_HISTORICAL = "SYNTHETIC_HISTORICAL"
    SIMULATED_LIVE = "SIMULATED_LIVE"
    ML_PREDICTION = "ML_PREDICTION"
    OPTIMIZER_RECOMMENDATION = "OPTIMIZER_RECOMMENDATION"
    DEMO_RESULT = "DEMO_RESULT"

class ProvenancedValue(BaseModel, Generic[T]):
    value: T
    provenance: ProvenanceTag
    uncertainty: Optional[dict] = None
    method: Optional[str] = None
    source: Optional[str] = None
```

## 5. Real Data Swap-In Guide

To replace synthetic data with real Baghewala field data:
1. Prepare CSV files matching the schemas in Section 4.
2. Upload via `POST /wells/{id}/import` with `Content-Type: multipart/form-data`.
3. Set `DATA_SOURCE=real` in `.env`.
4. Re-run `make train` to retrain ML models on real data.
5. All provenance tags will automatically change from `SYNTHETIC_HISTORICAL` to `FIELD_FACT`.

## 6. Noise Calibration

**If Volve data is available** (`VOLVE_DATA_PATH` set in `.env`):
- Script `data/calibrate_noise.py` fits Gaussian noise parameters (σ, drift, spike_prob, dropout_prob)
  from Volve production sensor data.
- Output: `data/noise_profiles/sensor_noise_config.json`

**If Volve data is NOT available** (default):
- Uses published noise parameters from literature:
  - Oil rate sensor: σ = 2% of reading, drift = 0.1%/day
  - Temperature: σ = 0.5°C, spike probability = 0.002/tick
  - Pressure: σ = 50 kPa, dropout probability = 0.001/tick
  - Motor current: σ = 1.5% of reading
- Source: Holloway, M.D. et al. (2012) *Non-Destructive Testing*, Wiley; industry practice.
