# ML Models Documentation
## Well-to-Surface Digital Twin — Baghewala Heavy Oil Field

> **Data disclaimer:** All models trained on SYNTHETIC_HISTORICAL data generated by the physics simulator.
> Models are NOT validated on real Baghewala field operations.
> Every prediction is labeled ML_PREDICTION with uncertainty bounds.

---

## Model 1: Production Forecaster

**Purpose:** Predict reservoir temperature, oil viscosity, and oil rate N days ahead.

**Algorithm:** LightGBM quantile regression (fallback: scikit-learn GradientBoostingRegressor)
**Outputs:** Three quantiles per target — q10 (lower), q50 (median), q90 (upper)
**Targets:** `reservoir_temp_c`, `oil_viscosity_cp`, `oil_rate_m3d`

### Features (42 total)
- Lag features: last 1, 3, 7, 14 days of production variables
- Rolling statistics: 3, 7, 14-day mean and std
- Physics-derived: production time, cycle number, bottomhole pressure
- SRP context: SPM, kWh/bbl, pump efficiency, rod float risk ratio

### Metrics (synthetic data, 80/20 split)
| Target | MAE (q50) | RMSE (q50) | 80% Coverage |
|---|---|---|---|
| reservoir_temp_c | 0.26 °C | 0.33 °C | 0.698 |
| oil_viscosity_cp | 34.8 cP | 43.0 cP | 0.708 |
| oil_rate_m3d | 0.005 m³/d | 0.006 m³/d | 0.726 |

### Limitations
- Trained on physics-simulator-generated synthetic data only
- Coverage slightly below theoretical 80% — expected for non-Gaussian targets
- Viscosity MAE appears large in absolute terms but is small relative to the 10–2000 cP range

## Model 2: Dyno Card Fault Classifier

**Purpose:** Classify dynamometer card shapes into 6 fault categories.

**Algorithm:** LightGBM classifier (fallback: Random Forest)
**Input:** 31 physics-meaningful features extracted from card arrays
**Output:** Predicted class + 6-class probability vector + top contributing features

### Classes
| Class | Physical Meaning |
|---|---|
| `normal` | Healthy pump operation |
| `rod_floating` | Rods cannot descend fast enough due to viscous drag |
| `pump_off` | No fluid in pump barrel — pump barrel empty |
| `gas_interference` | Gas compression before fluid enters pump |
| `fluid_pound` | Rods free-fall then impact fluid surface |
| `pump_unsetting` | Pump anchor loosened — erratic behavior |

### Features (31 total, from `ml/features/dyno_features.py`)
- Surface and downhole load statistics (peak, min, range, mean, std)
- Card area (energy per stroke proxy)
- Shape features: mid-stroke load, up/downstroke ratio, top-load flatness (rod float), bottom variance (gas/pound)
- Stroke geometry and damping attenuation
- Load gradient (fluid pound spike detection)
- Cross-card surface/downhole correlation
- Operating conditions: fillage, efficiency, rod float risk ratio, viscosity, SPM, stroke length

### Metrics (synthetic data, 80/20 stratified split)
| Metric | Value |
|---|---|
| Accuracy | 89.75% |
| F1 Macro | 0.876 |
| F1 rod_floating | 0.907 |
| F1 pump_off | 0.912 |
| F1 gas_interference | 0.852 |
| F1 fluid_pound | 0.803 |
| F1 pump_unsetting | 0.853 |
| F1 normal | 0.928 |

### Training Data Distribution
- normal: 37%, rod_floating: 20%, pump_off: 15%, gas_interference: 11%, fluid_pound: 9%, pump_unsetting: 8%
- 10% of labels contain intentional mislabeling noise to improve generalization

## Model 3: Rod Failure Risk Scorer

**Purpose:** Produce a continuous 0-100 risk score indicating how close a well is to a rod/pump failure.

**Algorithm:** XGBoost regressor (fallback: scikit-learn GradientBoostingRegressor)
**Input:** 14 SRP operating features
**Output:** Risk score 0-100 + top contributing factors

### Features (14 total)
`rod_float_risk_ratio`, `rod_float_risk_score`, `oil_viscosity_cp`, `spm`, `stroke_length_m`,
`motor_power_kw`, `kwh_per_bbl`, `pump_fillage_fraction`, `pump_efficiency_fraction`,
`polished_rod_load_kn`, `min_rod_load_kn`, `reservoir_temp_c`, `t_production_days`, `cycle_number`

### Risk Label Construction
- Days 0–14 before a failure event: 70–100 (linear ramp)
- Days 15–30 before a failure event: 50–70
- All other days: physics proxy score 0–60
  - `rf_contrib = clip((RF_ratio - 0.3) × 35, 0, 40)`
  - `mu_contrib = clip((viscosity - 100) / 60, 0, 20)`

### Metrics (synthetic data, 80/20 split)
| Metric | Value |
|---|---|
| MAE | 2.70 |
| RMSE | 5.93 |
| High-risk precision (>60) | 0.20 |
| High-risk recall (>60) | 0.97 |

**Note:** Low precision is expected with 28 failure events in synthetic data. Recall of 97% means the model almost never misses genuine high-risk periods. Precision will improve with real field data containing more failure events.

## Offline / No-Internet Operation

All models are pre-trained and shipped as `.joblib` files. The app loads them at startup.
**No internet connection, no GPU, and no PyTorch are required.**

Optional CNN classifier (not trained by default):
- Set `USE_CNN_CLASSIFIER=true` in `.env`
- Requires `torch` installed
- Falls back to LightGBM automatically if torch unavailable
